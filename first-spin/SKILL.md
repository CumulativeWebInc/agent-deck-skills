# THE FIRST SPIN — talent evaluation

## What this is

THE FIRST SPIN is the A&R department's talent-evaluation instrument: CWI's first-listen rubric in agent-readable form. It standardizes how an agent scores new music — hook, identity, replay value — the way a label scout would.

Department: **ar** | Category: `talent-evaluation` | Slot: `personality` | Version: `1.0.0`
Built and maintained by **Cumulative Web Inc**. Agent Deck SKU.

## When to use

- You are reviewing a demo or a new track and want a consistent scoring rubric.
- You need to explain WHY a track works (or does not) in structured terms.
- You are ranking catalog tracks for a playlist pitch or release priority.
